# Bundled fonts

Variable woff2 files (weight axis 100-900, `latin` and `latin-ext` subsets only), vendored so the app works offline.

| Family | Files | Source |
| --- | --- | --- |
| Noto Sans | `noto-sans-{latin,latin-ext}-wght-normal.woff2` | npm `@fontsource-variable/noto-sans` 5.3.0 |
| Noto Serif | `noto-serif-{latin,latin-ext}-wght-normal.woff2` | npm `@fontsource-variable/noto-serif` 5.3.0 |
| Noto Sans Mono | `noto-sans-mono-{latin,latin-ext}-wght-normal.woff2` | npm `@fontsource-variable/noto-sans-mono` 5.3.0 |

Licence: SIL Open Font License 1.1 (see `OFL.txt`). The fonts are copied unmodified from the package `files/` folders.
The `@font-face` rules live in `css/style.css`.
