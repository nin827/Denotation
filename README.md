# Denotation

**Your own notes, wiki and databases, in one quiet workspace.**

Denotation is a personal Notion/Obsidian-style workspace that runs entirely in your browser. Write pages out of blocks, nest them into repositories, and keep structured data in databases you can view as tables, spreadsheets, boards, calendars, galleries, charts and more.

There's no account and no server. Your workspace stays on your device unless you export it.

---

## What you can do

- **Write in blocks.** Headings, lists, to-dos, toggles, quotes, callouts, code, tables, columns, images, bookmarks, a table of contents and links to other pages. Type markdown shortcuts or pick a block from the menu.
- **Organise in a tree.** Group pages into repositories and nest them as deep as you like. Favourite the ones you use most, and find anything with quick find (Ctrl/Cmd + K).
- **Keep data in databases.** Typed columns (text, numbers, dates, lists, dictionaries and more), and every row is also a page you can write in.
- **See it your way.** Show one database as a table, a spreadsheet, a board, a list, a gallery, a calendar, a feed, a chart or a dashboard, with filters, sorts and groups.
- **Calculate.** Excel-like formulas in columns, plus pivot tables right inside your pages.
- **Bring data in and out.** Import and export CSV, and back up or move the whole workspace as one JSON file.
- **Make it yours.** Fonts, text and heading sizes, light or dark themes, and an accent colour from 24 hues or grey. By default it picks a random hue each time you open it.

## Getting started

| I want to… | Do this |
|---|---|
| Run it on my computer | Run `npm start` in this folder, then open http://localhost:8080 |
| Use it online | Open `https://<user>.github.io/<repo>/` in any modern browser. Nothing to install, no account. |
| Install it as an app | Chrome, Edge, Android: **⋯ → Settings → App → Install app**. iPhone/iPad: **Share → Add to Home Screen**. It then opens in its own window and works offline. |
